# Личная страница «Дизайнер и визуализатор» ЛР — 5

Учебный проект по веб-технологиям. Вариант 14. Автор: Ялпута Семён.

## О проекте
Одностраничный сайт-портфолио, объединяющий адаптивную вёрстку, базовую логику на JavaScript и интерактивное управление DOM-элементами с сохранением состояния между перезагрузками.

## Структура проекта
- `lab_4.html` — главная страница (разметка)
- `lab_4.css` — стили (включая адаптивность и тёмную тему)
- `script.js` — единый скрипт с логикой ЛР №4 и ЛР №5
- `README.md` — описание проекта
- `photos/` — папка с изображениями (`bg.jpg`, `photo_web.jpg`)

## Что реализовано

- **Поиск элементов:** `getElementById`, `querySelector`, `querySelectorAll`.
- **Манипуляции с DOM:** создание плиток цветов (`createElement`), добавление (`appendChild`), удаление (`remove`), изменение текста, атрибутов и классов.
- **Интерактивность:**
  - Кнопка «+ Добавить цвет» (создаёт плитку через `prompt` с валидацией HEX-кода).
  - Кнопка «Очистить палитру» (удаляет все плитки с подтверждением).
  - Кнопка «Удалить» на каждой отдельной плитке.
- **Тема и видимость:** переключение светлой/тёмной темы (изменение CSS-переменных через класс у `<body>`) и скрытие/показ секции палитры.
- **Обработка ошибок:** проверка существования элементов перед манипуляциями, логирование ошибок в консоль.
- **localStorage:** сохранение массива цветов и выбранной темы, автоматическое восстановление при загрузке страницы.
